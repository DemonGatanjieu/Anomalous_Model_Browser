# 素材库：保存画布选中节点

记录日期：2026-09-18。
**状态：后续需求，仅记录，本轮不开发。**

## 想做什么

在 ComfyUI 画布中选中一个或多个节点，通过一个方便的入口直接保存到素材库，方便以后复用，不必先生成图片或建立工作流配方。

- 单选：将这个节点及其当前参数保存为一份素材。
- 多选：将全部选中节点作为一个整体，保存为一份素材，不拆成多个独立条目。
- 保存选中节点之间的内部连线；与未选中节点相连的部分不自动扩展收录，不能留下指向不存在节点的无效连线。
- 保存不改变当前画布、节点参数或现有连接。

## 建议的最小交互

- 优先考虑节点或画布右键菜单中的“保存到素材库”，单选和多选共用入口；具体入口接入方式开发时核对 ComfyUI 能力。
- 轻量确认框显示“已选 N 个节点”，填写名称即可保存，标签可选；不强制提供封面。
- 未选中节点时不允许保存；成功提示只在实际保存完成后出现，并提供查看新素材的入口。失败保留输入，便于重试。
- 点击保存时固定节点选择与参数快照，后续切换选择不改变本次保存对象。

## 开发时注意

- 先核对现有节点素材、参数素材的保存与应用能力，复用素材库的存储、列表、详情和校验流程，不另建一套收藏系统。
- 当前图片/配方来源的保存接口不能直接假定支持画布快照；需要改协议时，明确新增来源的校验与兼容规则，不伪造图片来源。
- 单节点素材应能继续参与已有节点参数应用；多节点素材保留整体结构。首次开发需明确复用入口，保存成功后必须能在库中查看并通过相应流程使用。
- 先做好单选、多选、内部连线、外部连接边界、无选中节点和保存失败的验证；不借此扩展复杂节点组编辑器或自动收集依赖。
