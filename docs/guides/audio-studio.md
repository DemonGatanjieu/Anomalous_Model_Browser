# 音频工作台使用说明

插件里也能看简版：进入音频页后，点右上角的 **!**。

---

## 0. 先选引擎

音频页顶部有一个切换，可以选 **F5-TTS** 或 **GPT-SoVITS**。下面的角色、拖动规则和剧本台都会跟着变。
切换下面会写“适用节点：…”，告诉你这一页的东西能放到哪些节点上。

| 引擎 | 需要的节点包 | 适合什么 |
|---|---|---|
| F5-TTS | ComfyUI-F5-TTS | 一段 5~10 秒的录音就能模仿声音，不用训练 |
| GPT-SoVITS | Anomalous_TTS | 用你训练好的 GPT-SoVITS 角色模型，音色更还原；支持多角色对话和停顿 |

- **没装的引擎不会藏起来**，会标“未安装”，点进去能看到它能做什么、怎么装。页面不会弹窗打扰你。
- **F5-TTS 没装时**，声音库照样能管理和试听，只是生成不了。
- **装好节点包后**，重启 ComfyUI，再点“刷新音色”就能看到。
- **任何引擎没装，插件的其他功能都不受影响。**

### 左边的侧栏

- **分组**：GPT-SoVITS 的角色按语言分组（中文、日语、英语、未标语言），F5-TTS 的声音按文件夹分组。点组名可以收起，下次打开还是收着的。只有一组时不分组。
- **展开角色**：点角色名左边的小箭头，下面会列出它的每条声音（主声音、`{开心}` 这样的情绪）。点一条就在右边播放，再点一下停。
- **拖到节点上**：侧栏里的角色可以直接拖到节点上，和拖右边卡片的标题栏一样。F5-TTS 的单条声音也能拖到 Load Audio 上。
- **小红点**：角色名后面有小红点，说明这个角色有问题（读取失败，或者没有能当主声音的音频）。鼠标停在点上能看到原因。
- **搜索**：角色有 6 个以上时，顶上会出现搜索框，可以搜角色名、别名或情绪名。
- **拖文件**：把音频、模型文件拖到侧栏里的某个 GPT-SoVITS 角色上，会打开“添加文件”；拖到空白处就是导入新角色。

下面第 1~5 节讲 F5-TTS，第 6 节讲 GPT-SoVITS。

---

## 1. 准备声音文件

声音放在 `ComfyUI/input/F5-TTS/` 里，按下面的规则命名：

| 文件 | 作用 |
|---|---|
| `Arona.wav` + `Arona.txt` | **主声音**。`.txt` 里写这段录音说的原话 |
| `Arona.happy.wav` + `Arona.happy.txt` | **情绪声音**。台词里写 `{happy}` 时使用 |
| `Arona.angry.wav` + `Arona.angry.txt` | 同上，对应 `{angry}` |

- 情绪声音必须和主声音放在同一个文件夹，名字以主声音开头。
- 每条录音都要有同名 `.txt`，否则 F5-TTS 的下拉框里看不到它。
- 不想手动改名，就点 **新增音色**：选角色、填情绪、上传音频、填原话。文件名会自动按规则起好。原话是日语或韩语的话，可以点“智能转罗马音”。
- 放好文件后，ComfyUI 里要按 **R** 刷新一下节点，新文件才会出现在节点的下拉框里。

## 2. 音色卡片怎么用

每个角色一张卡片：

```
┌──────────────────────────────────────────┐
│ ⠿ 🎙 Arona                    3 角色音色预设 │  ← 标题栏：代表“整个角色”
├──────────────────────────────────────────┤
│ ⠿ ▶ MAIN   “それぞれの学園…”    [{main}]   │  ← 每一行：代表“这一条音频”
│ ⠿ ▶ ANGRY  “相手の雰囲気が…”    [{angry}]  │
│ ⠿ ▶ HAPPY  “うん、よし！…”      [{happy}]  │
└──────────────────────────────────────────┘
```

| 操作 | 结果 |
|---|---|
| 点 ▶ | 试听这一条 |
| 点右边的 `{标签}` 按钮 | 复制标签，粘贴到台词里 |
| **拖标题栏** → 放到 **F5-TTS 节点** | 节点的 `sample` 设为这个角色的**主声音** |
| **拖某一行** → 放到 **Load Audio 节点** | Load Audio 使用**这一条**音频 |

### 为什么要分“拖标题栏”和“拖单条”

F5-TTS 是按“角色”工作的：`sample` 只选主声音，情绪靠台词里的 `{happy}` 这种标签来切换。
如果把 `Arona.happy.wav` 放进 `sample`，写 `{happy}` 时它会去找不存在的 `Arona.happy.happy.wav`，`{main}` 也会变成开心的声音。
所以插件不允许把单条音频拖进 F5-TTS。

Load Audio 正好相反：它只用一条具体的音频，所以要拖某一行。

### 拖动时看提示

拖动时，鼠标旁边有一个提示框：

- **白色**：`松手：F5-TTS 使用 Arona 的主声音`。可以松手。
- **黄色**：拖到了不合适的节点，提示会写原因和正确做法，例如
  `F5-TTS 按角色选声音：请拖角色卡片的标题栏，情绪在台词里写 {happy}`。
  这时候松手什么也不会改。

目前支持的节点：

| 节点 | 拖什么 | 说明 |
|---|---|---|
| F5-TTS Audio / F5-TTS Audio Advanced / F5-TTS Audio From Model | 标题栏（整个角色） | 如果节点的 `sample_audio` 接了线，F5-TTS 会忽略下拉框，插件也会拒绝写入 |
| Load Audio（ComfyUI 自带） | 单条 | 可以把它的输出接到任何需要“参考音频”的节点 |

其他节点一律不接收。这是故意的：插件不靠猜，避免写错地方。

## 3. 剧本台：一段话多种情绪

1. 点 **打开剧本台**，在上方选角色。
2. 把整段台词粘贴进去，点解析。每句话会变成一张卡片。
3. 每张卡片点一下情绪（main / happy / angry……）。也可以直接改字，或者用 ✂ 在光标处拆开、合并、删除。
4. 下方会显示打包好的剧本，例如：
   ```
   {main} 老师，早上好！
   {happy} 今天也要加油哦！
   ```
5. 写进节点，两种方式任选：
   - 点 **推送到节点**：写进选中的 F5-TTS 节点。画布上只有一个 F5-TTS 节点时，不用选。
   - 按住 **拖到节点**，把整段剧本拖到某个 F5-TTS 节点上。

两种方式都会同时设置 `sample`（主声音）和 `speech`（带标签的台词）。节点里原来有台词时，会先问要不要覆盖。

## 4. 生成和找回结果

- 画布上还没有工作流时，点 **载入阿罗娜工作流到画布**，会得到一个现成模板（F5-TTS → 保存音频）。
- 点运行后，生成的音频在顶部的 **音频库**：
  - 每条会显示台词、声音和种子，可以试听、按台词搜索、删除。
  - 只在预览里出现、还没保存的临时结果，列在“未保存的预览”里，点 **保存** 就能存到 `output/audio/`。

## 6. GPT-SoVITS（Anomalous TTS）

### 设置

切到 GPT-SoVITS 后，工具栏上有 **导入角色**。还没有角色时，中间是一块空的导入区，直接把文件拖进去或点 **+ 导入角色**。

存放位置、底模这些设置在左边侧栏的最下面：**GPT-SoVITS 设置**，点开是一个窗口。底模缺了不会挡路（第一次生成时会自动下载），所以只在这个入口上放一个小黄点：已有角色用到的底模还没下载时才出现。窗口里第一行写着缺几个、多大，可以 **现在下载**，也可以点 **不再提醒**。以后导入了要用新底模的角色（比如第一个中文角色），小黄点会再出现。缺 Python 包时是小红点，不能关掉。下载或移动角色的进度也写在这个入口下面。

窗口里有：

- **角色存放位置**：导入的角色都放在这里，默认 `ComfyUI/models/gpt_sovits/`。点 **更改…** 选一个新文件夹，会问要不要把现有角色 **移过去**：选“移过去”会逐个移动并显示进度（同一个盘上瞬间完成，跨盘先复制再删原来的；遇到同名文件夹或出错会停下，没移的角色照样能用）；选“不移动”，它们留在原处照样能用，只有以后导入的放到新位置。都不用重启，也不用改 `extra_model_paths.yaml`。
- **其他位置**：以前的存放位置里还没移走的角色，以及 `extra_model_paths.yaml` 里的文件夹。以前的存放位置点 **×** 就不再列出，文件不会删除。
- **底模**：每个底模是已就绪、缺少还是下载中。可以单个 **下载**、**全部下载**，或者 **使用已有的 GPT-SoVITS 整合包**（选整合包里的 `GPT_SoVITS` 文件夹），就不用再下一遍。只说日语的角色不需要中文底模；标“可选”的缺了也能用。
- **Python 包**：缺了哪种语言要的包，会给出安装命令，复制到命令行运行后重启 ComfyUI。

导入表单里选了语言后，下面会用小字写出生成时还要用到哪些底模。

这些操作会读写运行 ComfyUI 那台电脑上的文件，所以只能在那台电脑上用；从别的设备打开时按钮是灰的。

### 导入角色（新用户从这里开始）

点 **导入角色**。第一次打开时会有一段遮罩引导，一步步指给你看；之后随时点窗口右上角的 **?** 再看一遍。窗口顶上写着现在在哪一步：**① 选方式 → ② 放入文件 → ③ 导入**。

**① 选方式**：窗口先问“你手上有什么？”

- **一个角色**：这个角色的 GPT 模型、SoVITS 模型和几段参考音频。会一步步带你放好。
- **很多角色 / 整合包**：一次导入好几个角色，或者选一个 GPT-SoVITS 整合包文件夹，会按名字自动分好。
- **给已有角色加声音**：选一个已经导入的角色，往里面加参考音频、台词文件或新模型。

直接把文件拖到音频页或这个窗口上，会跳过这一步，按“很多角色”处理（一个角色的文件也能正确认出来）。选错了可以点 **‹ 换一种方式**（还没放文件时才有）。

**② 放入文件**：每个角色一张卡片，卡片最上面是一份**待办清单**，永远高亮下一步，按钮就在那一行：

1. 放 GPT 模型（`.ckpt`，在整合包的 `GPT_weights` 文件夹里）
2. 放 SoVITS 模型（`.pth`，在 `SoVITS_weights` 文件夹里）
3. 放几段参考音频（3~10 秒、说得清楚的）
4. 选一段当主声音：在音频列表里点 **☆**，变成 **★** 就是主声音（一般会自动选好）
5. 给角色起个名字（一般会从模型文件名自动填好；卡片标题就是名字，可以直接改）

做完一项就打勾；卡片标题旁写着“还差 N 步”，全部完成变成绿色的 **可以导入**。任何时候都可以直接把文件拖进窗口，会自动放到对的地方。

参考音频一段一行：填上情绪名（例如“开心”）就成了 `{开心}`。台词会自动从同名 `.txt` / `.lab` 或标注文件里找；台词框是黄框表示台词取自文件名，请确认；红色虚线框表示没找到，可以粘贴，也可以把 `.txt` / `.lab` / `.list` 拖到框里。卡片底部是台词文件和 **角色说的语言**（一般自动判断就行）。

**很多角色 / 整合包**时：

- 模型按名字配成角色：`ALuoNa-e15.ckpt` 和 `ALuoNa_e16_s224.pth` 都算 `ALuoNa`。好几轮（e5、e10、e15）时自动用轮数最大的。
- 音频和台词文件按所在的文件夹名（比如 `参考音频/ALuoNa/`）或文件名开头分给对应的角色。
- 分不出来的放在最上面一张黄色卡片里，在每个文件右边选它属于哪个角色。分错的文件，鼠标移上去，右边也能改。
- 卡片收起时只有一行，点开看详情，一次只展开一张。右上角 **+ 继续添加** 可以再加文件，**+ 新角色** 手动加一个角色。

**③ 导入**：底部按钮写着“导入 N 个角色”，只导入“可以导入”的那些。每个角色单独导入，一个失败不影响其他的；失败的留在窗口里标红，改好再点一次。全部导入完窗口自动关闭，并滚到新角色的卡片。底部还写着会保存到哪里（想换地方，在设置里改存放位置）。

节点会建好 `角色名/GPT_weights/`、`SoVITS_weights/`、`参考音频/` 和设置文件。**一律复制，原文件不动**；中途出错时存放位置保持原样，不会留下半个角色。

给已有角色加音频或情绪：点卡片上的 **添加文件**，或者把文件拖到那张卡片（或侧栏里的角色名）上。这时放进来的文件都归这个角色，模型可以不放。已有的文件不会被覆盖，主声音也不会被换掉（除非你点了“★ 主声音”）。

一条一条加也不会越加越乱：

- 角色里已经有一模一样的文件，那一行是灰色的“角色里已有，跳过”，不会再复制一份。
- 标注文件（`.list` 等）再放一次，只会把新的行追加进角色里已有的那份，写着“合并新台词”。
- 只加一条音频、不带标注文件时，台词会从角色里已有的标注文件里找。
- 只有“同名但内容不同”的文件会标红，不能导入。改个文件名，或者删掉那一行。

### 角色文件夹的规则

- 一个角色就是一个文件夹，里面至少有一个 `.ckpt`（GPT 权重）和一个 `.pth`（SoVITS 权重）。
- 角色文件夹放在存放位置里（默认 `ComfyUI/models/gpt_sovits/`），也可以放在 `extra_model_paths.yaml` 里写的 `gpt_sovits` 目录。自己往存放位置里放整理好的角色文件夹也可以，点 **刷新音色** 就能看到。
- 同一个角色有日配、中配两个版本时，会显示成 `阿罗娜/日配`、`阿罗娜/中配` 两个角色。

### 编辑情绪

点角色卡片上的 **编辑情绪**：

1. **主声音 `{main}`**：选一条 3~10 秒的参考音频。留空的话，节点会自己挑一条。
2. **情绪**：每行填一个情绪名（例如“开心”），再从角色文件夹里选一条参考音频。输入框可以直接打字搜索文件名。
3. **参考台词**：可以不填，节点会自己去找同名 `.txt` 或 GPT-SoVITS 的标注文件。
4. 点 **保存**。设置会写进角色文件夹里的 `anomalous_tts.json`，由节点检查后保存。选了不存在的文件时，会提示原因，什么都不会改。

文件名本身带情绪的音频（例如 `Arona_Talk.开心.wav`）会被自动识别，不用再填一遍。只是扩展名的部分不算情绪，例如 `Arona_Talk.ogg.wav`、`Arona_Talk.ogg (1).ogg`。

角色列表会缓存一会儿，切换页面不会卡。往模型文件夹里加了角色或音频后，点 **刷新音色** 才会重新读取。

### 用起来

- **拖卡片标题栏** → 放到 **角色语音 (GPT-SoVITS)** 节点：节点的“角色”设为这个角色。
- **剧本台**：切到 GPT-SoVITS 后，剧本台列出的就是这些角色。推送时，节点的“角色”和“台词”会一起填好。
- 台词里还可以直接写：
  - `[普拉娜]`：换人说。要写角色名或别名。
  - `[pause:1s]`：停顿。
- GPT-SoVITS 的参考音频在模型文件夹里，不在 `input/` 里，所以不能拖到 Load Audio。

## 7. 常见问题

| 现象 | 原因和解决 |
|---|---|
| 拖到节点上提示“列表里还没有 …” | ComfyUI 还没刷新节点定义。按 **R** 后再拖 |
| 卡片上黄色提示“缺少主音色” | 只有情绪文件，没有 `角色.wav`。补上主声音，F5-TTS 才能用标签 |
| `{标签}` 按钮是灰的 | 这条情绪文件和主声音不在一起，或者格式不一样，F5-TTS 找不到它 |
| 标题栏拖不动 | 这个角色没有主声音 |
| 拖到别的语音节点被拒绝 | 这个节点还不在支持名单里。可以先放 Load Audio，再把它的输出接过去 |
| 提示“这是 GPT-SoVITS 的声音，F5-TTS 节点用不了” | 两种引擎的声音不能混用。切到对应的引擎，拖到它自己的节点上 |
| GPT-SoVITS 角色卡片上提示“没有找到合适的主声音” | 角色文件夹里没有 3~10 秒、找得到台词的音频。点“编辑情绪”手动选一条 |
| 新放进去的 GPT-SoVITS 角色或音频没出现 | 点 **刷新音色**。节点那边在 ComfyUI 里按 **R** 刷新下拉框 |
| 侧栏里看不到“GPT-SoVITS 设置”，工具栏上没有“导入角色” | Anomalous_TTS 版本太旧（没有接口版本 3）。更新 Anomalous_TTS 后重启 ComfyUI |
| “导入角色”是灰的 | 页面是从别的设备打开的。导入会写文件，只能在运行 ComfyUI 的电脑上做 |
