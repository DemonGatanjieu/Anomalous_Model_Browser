# AI 工具考试（MCP 工具改动后用）

AMB 给 AI 软件的工具，以轻量模型（Gemini Flash）能顺畅用为准。改工具（加一个、改说明、改参数）以后，不靠一次次手试，而是让 Flash 把下面的固定考题做一遍，再用打分脚本看数字。

## 预算（`tests/test_tool_budget.py` 自动检查）

2026-10-26 量的：53 个工具，约 4.3 万字符（约 1.1 万 token），说明书约 3200 字符。Gemini 3.8 Flash 在 Antigravity 里用它们调用了约 570 次，几乎没有调用错误。所以现在这样就是上限：

- 工具总数不再增加：加一个，就要合并或删掉一个。
- 每个工具的说明不超过 700 字符（`show_panel` 例外：它的各种块没有自己的格式定义，说明就是格式）。
- 一次调用最多 2 个必填参数，其余都有默认值。
- 报错要写下一步怎么做（哪个节点、缺什么、调哪个工具），不要只转发原始报错。
- 所有工具都直接给，不做"转一道"的调用：Antigravity 自己会在第一次用某个工具前读它的说明文件，服务器这边再做一层按需只会让 AI 多绕路（10-26 那次 29 次调用里有 18 次花在查工具和转一道上，所以"日常"工具组删了）。

要放宽这些数字，必须同时跑一遍考试，证明 Flash 还是顺的。

## 怎么考

1. 在隔离的测试 ComfyUI（8199 端口，自己的 user 和 output 文件夹，模型只读）上开 AMB。关卡里把"下载模型"和"挪动模型文件"设成"不许做"，不扫描。
2. AI 软件连到这个测试 ComfyUI（Antigravity：MCP 设置里 anomalous 的地址改成 8199，考完改回来）。连之前先问用户。
3. 每道题开一个新对话，把"开头那句话"发给 AI；需要你回答的地方照"你怎么答"去答。
4. 全部做完后打分：

   ```bash
   node tools/tool_exam.mjs <测试 ComfyUI 的 user 文件夹>/anomalous/ai_tasks --since=2026-10-26T20:00
   ```

   每道题一行：AI 调用了几次（calls）、失败几次（failed）、绕路几次（detours：以前版本的查工具，或者拿着旧的工具列表来调用）、问了你几次、你答了几次、跑了几次图、失败几次、有没有收尾、用了几分钟。最后一行是总数，下面一行是失败率和绕路率。

5. 和上一次的分数比：失败率、绕路率不能变高，每题的调用次数不能明显变多。

## 考题

| # | 开头那句话 | 你怎么答 | 合格 |
| --- | --- | --- | --- |
| 1 | 用 Anomalous 出一张图：画布上的文生图工作流，提示词写"一只在窗台上晒太阳的橘猫"，跑一张。 | 不用答 | 一次 `run_workflow` 出图；不超过 6 次调用 |
