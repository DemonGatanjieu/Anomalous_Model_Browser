# 素材库核心逻辑与验收基线

**更新**：2026-09-09，入口迁移、提示词搭配与节点应用融合。架构契约见 `docs/architecture/material-library.md`。

## 当前能做什么

素材库是人工精选和复用层，保留配方、提示词笔记和节点助手的直接使用入口。

- 从主图库或配方图库的生成 PNG 保存图片与完整工作流，也可保存单个或多个节点参数。
- 按名称、标签、节点类型搜索；按类型和标签筛选；每页 48 条。
- 在详情修改名称和标签；相同图片、素材类型和节点范围再次保存时提示重复，可确认另存。
- 浏览模式点击卡片进入详情；选中单节点后的应用模式点击卡片写入匹配参数，多组候选需选择。
- 完整素材可打开原始工作流；节点助手可按精确 node.type 应用节点参数。

## 真实数据类型

| kind | 内容与能力 |
| --- | --- |
| `image_workflow_snapshot` | 图片、完整 UI workflow、模型引用；可打开工作流或复用节点参数 |
| `image_node_selection` | 图片和完整来源依据保存在本地，只展示和复用已选节点；不能打开隐藏工作流 |
| `recipe_parameter_selection` | 配方或参数方案的选中节点，通过节点助手复用 |
| `prompt_note_bundle` | 提示词、翻译、配套模型；可载入新笔记 |
| `prompt_text` | 提示词与翻译，不含模型；可复制或载入新笔记 |

前两类保留原图，其他类型没有图片资产。`reference_image` 目前只代表可查看保存的图片，尚不能复制到 input 或配置 LoadImage。

配方可保存全部、单节点或多选参数；提示词笔记可保存整份组合或仅提示词。保存后可直接“查看素材”。笔记素材能载入为新笔记，不覆盖原笔记；其中文字段是翻译，不是负面提示词。

图片来源需要带 UI workflow 的 PNG。只有 API prompt 的图片、损坏元数据、越界路径和超大图片会被拒绝。

## 保存与本地数据

数据在 ComfyUI 用户目录的 `workflows/anomalous_materials/`：JSON 记录配套 `.assets/<素材文件名去掉后缀>/` 下的原始 PNG 与 WebP 预览，不写回插件源码目录。

保存先暂存 JSON 和图片，资产就位后再发布记录。最终记录写入失败会回滚新增资产；名称和标签修改采用原子写入。删除只清理该素材及其私有图片，不影响原始出图。

提示词笔记独立保存在 `workflows/anomalous_notebooks`，旧文件采用可恢复复制并保留原件；素材副本与原笔记各自独立。

## 浏览与性能边界

- 列表只返回摘要；摘要按文件路径、大小、mtime、ctime 缓存，最多 4,096 条，检测文件新增、修改和删除。
- 素材详情请求 `material_full?include_workflow=0`，只返回元信息与所选范围内的完整参数块。提示词节点默认展开，其他节点默认闭合，首次展开才创建参数 DOM；再次展开复用内容。
- “全部展开／收起”根据实际展开状态切换。图片工作台中可勾选的节点卡保持默认闭合。
- 点击“打开完整工作流”才请求 `include_workflow=1`，返回原始 workflow，`node_blocks` 为空，避免两份 widget 值。
- 旧调用不传该参数时，完整素材仍保留旧返回格式；节点参数素材始终不返回隐藏 workflow，显式请求打开时返回 403。
- 后端在工作线程读取、整理和序列化详情；节点选择先过滤再复制参数。磁盘中仍保留完整来源，读取记录时仍需解析它。
- 搜索取消旧请求；返回列表保留筛选并释放详情 DOM。主图库复用短期目录快照，刷新和删除即时失效。
- 图片工作台另有 16 条解析缓存、可取消导航和延迟模型预览查询。

**仍待优化**：节点助手按类型查询尚未分页；重复确认前已暂存图片，另存会重复处理。大量提示词节点、单个长提示词以及用户主动“全部展开”仍可能产生较多 DOM；本轮没有实现虚拟列表。

## 职责边界

- 素材库保存和展示内容，不判断模型身份。
- 素材库与节点助手共用事务性应用，跳过种子；只搬运已有 Hash 证据，不自动全图修复。
- 模型医生负责身份判断：完整文件哈希一致可自动修复，只有大小一致需确认当前节点，证据冲突必须拒绝。
- 文件名、路径、封面、素材名和模型大小不能成为自动身份依据。
- 提示词和动态名称使用文本 DOM，界面文案进入 `locales.js`。

## 关联模块

- `api/materials.py`：存储、摘要、筛选分页、详情响应、资产和节点类型查询。
- `ui_materials.js`：素材列表、筛选、编辑、详情与工作流打开。
- `material_inspector.js`：共享参数展示与惰性渲染。
- `ui_gallery_detail.js`：图片工作台、图片与节点保存。
- `ui_doctor.js`：按当前节点类型复用参数。

## 固定冒烟清单

1. 点卡片进详情；点删除或快捷打开不会同时进入详情。
2. 连续搜索取消旧请求，返回列表保留筛选条件。
3. 名称或标签保存失败时显示失败，编辑内容可重试。
4. 2,001 节点样例仅提示词默认展开，普通节点无参数内容 DOM；单节点和全部展开／收起均正常。
5. 详情响应无 workflow；打开完整素材才读取原图，并保留 seed 和模型 Hash。节点参数素材不能请求隐藏工作流。
6. 剪贴板失败有可见提示；再次复制保留原始提示词空白。
7. 从节点助手应用参数仍跳过种子并按目标节点 ID 重映射 Hash。

本轮新增本地回归：`tests/test_material_details.py` 覆盖详情协议、兼容性和选中范围；`tests/material_inspector_lazy.mjs` 覆盖大列表惰性渲染和复制反馈。测试目录继续只供本地 AI 验证。
