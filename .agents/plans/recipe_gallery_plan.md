# 配方专享图库 (Recipe Gallery) 实施规划书

## 1. 核心需求
目前的保存配方封面图仅能读取基础模型的缩略图。为了展示配方的真实出图效果，我们需要新增一个【配方专享图库】功能，能够自动抓取历史出图 (ComfyUI `output` 文件夹) 中，使用相同节点组成的生成结果，供用户查看、对比参数并设为封面。

## 2. 问题分析与解决方案：结构性指纹 (Structural Fingerprint)
目前的 `_workflow_fingerprint` 对整个 workflow 进行硬哈希，哪怕 Seed 发生一次改变，指纹也会完全不同。这将导致“换种子抽卡”的出图无法匹配原配方。

**最终采用两种指纹：**
1. `sha256-structural-v1` 仍用于配方/历史版本完整性，保留工作流结构和参数，只剔除已知运行易变值。
2. `sha256-node-types-v1` 专门用于图库发现，只保存排序后的节点类型及数量，不关注参数、节点 ID 或序列化格式。这样不同提示词、模型、采样参数和 seed 生成的结果也能进入同一配方图库。

图库发现兼容 PNG 内嵌的 ComfyUI `workflow` 和 API `prompt` 元数据。用户点击图片后，才读取有大小上限的节点参数，展示配方与图片的差异；参数比较不反过来影响图库匹配。

## 3. 具体实施步骤

### 阶段一：后端算法升级 (api/recipes.py)
- 修改 `_workflow_fingerprint` 方法，增加一个剥离易变参数的过滤器 `_clean_volatile_params(workflow)`。
- 按需扫描 ComfyUI 的 `output` 目录下最近 200 张 PNG，不建立常驻缓存、不后台轮询。读取每张图内嵌的 `workflow` 或 `prompt` 数据，计算节点组成签名并返回匹配图片。
- 开放新 API 端点：`GET /anomalous/recipe_gallery?fingerprint=<...>`，返回匹配的图片路径列表。
- 开放参数查看 API：`GET /anomalous/recipe_gallery_compare`，返回单张图片的有界节点参数和配方/图片差异。

### 阶段二：前端 UI 升级 (web/modules/ui_recipe_detail.js)
- 在配方详情页（概览、参数、历史版本右侧）新增第四个标签：【图库 (Gallery)】。
- 标签页上动态显示匹配到的图片数量，例如 `图库 (12)`。
- 图库内使用瀑布流布局渲染这些真实出图。

### 阶段三：联动与封面设定
- 在图库的每一张图片悬浮状态添加按钮：**🖼️ 设为配方封面**。
- 点击图片展开参数对比；“查看原图”仍可打开大图查看器。
- 点击时，读取该原图数据并调用已有的 `update_recipe` 逻辑将其转化为缩略图，永久写入 `assets` 文件夹中作为主封面。
- 在 `locales.js` 中废弃生硬的“模型封面快照”表述，引导用户直接去专属图库中挑选真实成果图。
